# README 配图设计 · 清晰成稿

以“清晰成稿”为视觉方向。让正文、卡片、素材和文件通过可见的顺序建立关系，阅读者不用先读一大段说明，就能看见内容从哪里来、最后到哪里去。每张画布只保留一个主命题，用经过细致校准的留白、边界和对齐呈现完成感。

色彩延续产品的白色工作区和深墨色文字。灰白底承托内容，少量柔黄色对应实际截图里的文字高亮，克制的青绿色只标记转换、选中和完成。所有颜色服务于信息关系，不用渐变、发光或装饰性仪表盘抢走正文的注意力。

尺度从一个足够醒目的中文标题开始，随后交给文档轮廓、分页、裁剪框、时间轴和文件树。英文字体采用 Instrument Sans，代码与文件名采用 DM Mono，中文使用系统无衬线。字距、基线、内边距与组件节奏逐处校准，以精细制作的版式维持同一套阅读秩序。

图形使用可解释的几何元素：纸页代表内容，框线代表裁剪，轨道代表时间，目录代表可携带的稿件。示意素材由原生几何图形绘制，不暗示额外的模板库或自动生成图片能力。每一处连接与每一个控件，都对应仓库已有能力，避免用设计补出尚不存在的功能。

细节以克制完成：统一细线图标与圆角，检查不同形态之间的光学平衡，优先删掉干扰而不是增加装饰。四张设计图明确标为功能示意，工作区截图使用用户提供的原图。最终以高清 PNG 输出，确保在 GitHub README 缩放后仍有清楚的主次关系。
